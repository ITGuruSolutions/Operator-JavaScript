Operators are tools used in JavaScript to perform operations on values or variables. Let's understand them one by one with examples.

1️⃣ Arithmetic Operators

OperatorUseExampleResult

Example: Add and Multiply

let x = 10;
let y = 3;

let sum = x + y;
let multiply = x * y;

console.log("Sum:", sum);
console.log("Product:", multiply);
